# Content planning

## 计划表

`reports/PAPER_CONTENT_PLAN.md` 对每个实际子问题记录：任务、主张、模型/算法、证据 Artifact、预期表图、验证方式、限制和状态。计划是写作门禁，不是论文正文。

## 最低结构

根据比赛模板调整标题，但内容通常包括摘要、关键词、问题重述、问题分析、假设、符号、逐问建模与求解、检验或稳健性、模型评价、结论、参考文献和附录。

每个子问题至少形成“问题 → 方法 → 结果 → 解释 → 验证/边界”的闭环。不能用统一的敏感性分析模板替代适合题型的验证：预测题看泛化与残差，优化题看可行性和情景变化，评价题看权重与排序稳定性，机理题看参数、拟合与物理合理性。

## 内容门禁

- 题目有几问就写几问，不保留模板多余章节。
- 公式后解释符号和单位；图表后解释其支持的主张。
- 附录提供本次运行所需的复现信息，不只列文件名。
- `EVIDENCE_GAP` 必须被补齐，或在正文中转化为明确限制。
