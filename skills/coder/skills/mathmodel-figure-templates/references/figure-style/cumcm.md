# CUMCM profile

Optimize for Chinese academic readability, model transparency, and compact page use.

- Use Chinese labels and captions unless the chosen template requires otherwise; keep numbers and Latin symbols typographically consistent.
- State units on axes and tables. Do not place long section-like titles inside figures.
- Technical routes and indicator systems may use DrawIO; formula-rich mechanisms use TikZ; computed evidence uses Matplotlib.
- Keep palettes restrained and printable. Use shape, line style, hatching, or labels so conclusions do not depend on red–green discrimination.
- Align figure order with the problem sequence and explain every figure in the surrounding text.
- Prefer a clear route map and a few decisive result figures over large decorative dashboards.
- Check the current contest notice and official template; this profile does not hard-code annual page or file rules.
