# MCM/ICM profile

Optimize for rapid judging, narrative continuity, and English-language clarity under page pressure.

- Every major figure must support a claim in the Summary or main solution, not merely document that code ran.
- Use concise English labels, explicit units, and captions that state what the reader should learn.
- Prefer one explanatory overview plus a small set of high-value result figures; do not fill the paper with redundant diagnostics.
- Keep method colours consistent across questions and preserve grayscale readability.
- For model structure, use TikZ or DrawIO; for computed evidence, use Matplotlib from frozen results.
- Combine related evidence into aligned Panels only when each Panel contributes a distinct step in the argument.
- Check the current COMAP rules for page and submission requirements; this profile does not freeze annual competition rules.
