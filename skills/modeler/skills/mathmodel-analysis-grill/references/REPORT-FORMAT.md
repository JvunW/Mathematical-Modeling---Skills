# MODEL_GRILL_REPORT.md 格式

```markdown
# 用户建模思路访谈记录

## 访谈对象

- 题面与附件：...
- 访谈时间：...
- 状态：WAITING_FOR_USER / COMPLETE / NEEDS_CLARIFICATION / SKIPPED_BY_USER

## 建模思路十问

1. 问题：...
   为什么要问：...
   用户回答：...
   提取出的用户决定：...

2. 问题：...
   为什么要问：...
   用户回答：...
   提取出的用户决定：...

<!-- 按同一格式保留至第 10 题 -->

## 用户明确决定

- ...

## 用户尚不确定的事项

- ...

## 回答间的冲突与澄清

- ...

## 传给建模分析阶段的约束

- 必须遵循：...
- 可以比较后选择：...
- 不应采用：...
```

报告记录的是**用户实际表达的思路**，不是 Agent 对自己方案的审查结果。不得编造、补全或把 Agent 推荐项写成用户决定。用户原始回答应保留含义，可以压缩措辞但不能改变立场。
