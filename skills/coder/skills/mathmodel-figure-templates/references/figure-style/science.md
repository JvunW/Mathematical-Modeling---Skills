# Science profile

Use a compact, editorial figure style with strong panel logic and restrained colour. Treat this as a visual profile, not a substitute for the current Science-family author instructions.

- Let each panel answer one question and order panels to mirror the Results narrative.
- Use a sans-serif type system, white background, clean axes, and few visual levels.
- Reserve one accent for the main conclusion; use neutral comparisons and color-vision-safe alternatives.
- Prefer direct labels and shared legends; remove decorative titles, heavy grids, shadows, gradients, and 3D chart effects.
- Export editable vector line art and inspect raster panels at their final physical size.
- State units, uncertainty, sample size, and statistical definitions in the legend or caption.

Compared with the Nature profile, allow slightly stronger contrast when it improves rapid comparison, but never turn saturation into the evidence.
