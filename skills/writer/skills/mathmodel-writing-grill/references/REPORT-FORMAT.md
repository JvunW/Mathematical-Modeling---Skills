# PAPER_GRILL_REPORT.md 格式

```markdown
# 论文质询报告

## 审查对象

- 门禁：论证计划 / 正文成稿
- 排版引擎：LaTeX / Typst / Word
- 题目与结果版本：...
- 审查时间：...

## Round 1

### 问题与回答

1. 问题：...
   用户回答：...
   写作决定：...
   证据来源：...
   写回位置：`PAPER_CONTENT_PLAN.md` 或论文章节 ...

### 本轮发现的冲突

- ...

### 本轮已确认决定

- ...

## Round 2

仅在实际发生时保留。

## Round 3

仅在实际发生时保留。

## 最终论文主线

- 核心贡献：...
- Q1：方法、证据、结论和边界
- Q2：方法、证据、结论和边界

## 证据缺口与降级处理

- 缺口：...
  处理：补实验 / 删除论点 / 降低结论强度

## 写作门禁

- 状态：READY / READY_WITH_RISKS / BLOCKED
- 原因：...
```

报告用于保存决策和风险，不复制整篇论文，也不记录纯排版微调。
