# 论文 Skills 优化说明

本项目当前重点是面向高教社杯全国大学生数学建模竞赛（CUMCM）的论文生成、排版、文献检索和提交前验收。

## 优化内容

### 1. 论文内容

- 根据题面建立实际问题清单，不再默认三问结构。
- 每个问题完成“题目要求 → 数据口径 → 模型 → 算法 → 真实结果 → 验证 → 局限 → 明确回答”的闭环。
- 使用 `PAPER_CONTENT_PLAN.md` 绑定问题、论点、结果文件、图表和章节。
- 缺少真实证据时标记 `EVIDENCE_GAP`，禁止编造数值或用空泛结论填充。
- 摘要、正文、结果和最终结论必须逐项一致。
- 回归、生存分析、分类和优化模型分别使用匹配的验证方法。

### 2. CUMCM 结构与排版

- 保留 CUMCM 模板，但模板示例正文、示例数值和示例图表不能作为论文内容。
- 入口文件按题目实际问题数量组织，不强行保留多余问题章节。
- 电子版从摘要页开始，不放目录、承诺书和编号专用页。
- 表格优先使用三线表；窄表保持自然宽度，宽表使用版心约束。
- LaTeX 支持 `tabularx`，Typst 支持可调表格宽度。
- 颜色保持克制，图表在灰度打印时仍应可读。
- 不设置固定页数、表格数或图片数，只检查内容是否失衡。

### 3. 参考文献

检索顺序：

```text
OPENALEX_API_KEY 已配置
    → 使用 OpenAlex

OpenAlex 未配置或不可用，Codex 有联网搜索
    → 使用 Codex 联网搜索

没有联网工具
    → 提示用户手动使用 ChatGPT Deep Research
```

- Codex 联网搜索不需要额外的 OpenAI API Key。
- Deep Research 仅作为人工发现工具，不作为本地脚本自动调用接口。
- 候选文献必须用 DOI、Crossref、Semantic Scholar、arXiv、PubMed 或出版社页面核验。
- 检索式、来源、核验状态和采用理由写入 `reports/LITERATURE_REPORT.md`。
- 禁止凭模型记忆编造参考文献。

### 4. 论文验收

验收检查包括：

- 问题数量和章节是否完整；
- 每问是否有模型公式、真实结果和验证证据；
- 是否存在占位符、模板示例或内部工作流痕迹；
- 摘要、正文和结果数值是否一致；
- 图表路径、表格样式和编译结果是否正常；
- 附录是否包含本次运行所用的完整源代码；
- 目录、页数、空白页和最终 PDF 页面质量是否符合 CUMCM 要求。

## 当前工作流

```text
题目问题清单
→ 结果与证据规划
→ 按问题生成正文
→ 文献检索与核验
→ 逐问内容验收
→ 编译和 PDF 视觉检查
```
