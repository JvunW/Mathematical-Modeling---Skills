# TikZ component catalog

Copy only the components that support the Figure Contract. Each file is a locally scoped fragment intended for use inside a `tikzpicture`; rename node identifiers when composing more than one instance.

| Component | Purpose |
|---|---|
| `attention-heatmap.tex` | compact matrix evidence |
| `bar-chart.tex` | small categorical comparison Panel |
| `line-chart.tex` | small trend or convergence Panel |
| `formula-box.tex` | visually anchored equation and interpretation |
| `pipeline-stages.tex` | left-to-right main flow |
| `layer-stack.tex` | repeated model layers or scenarios |
| `feedback-loop.tex` | explicit iterative or control loop |
| `multi-zone-palette.tex` | restrained semantic zones and legend |

The local versions are adapted or clean-room rewritten for mathematical-modeling use. They intentionally avoid invented benchmark values and decorative complexity.
