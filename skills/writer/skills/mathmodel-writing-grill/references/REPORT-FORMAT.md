# PAPER_GRILL_REPORT.md 格式

```markdown
# 论文用户决策十问报告

## 任务信息

- 排版引擎：LaTeX / Typst / Word
- 题目与结果版本：...
- 报告更新时间：...

## 论证计划门禁十问

- 提问时间：...
- 回答完成时间：...

1. **问题**：<展示给用户的原问题>
   **用户回答**：<保留原意，不代答>
   **写作决定**：<由回答形成的决定>
   **影响位置**：<章节、论点、图表或结论>
   **证据状态**：<已有证据、不确定、冲突或需退回>

2–10. <逐题记录，不得省略>

### 计划门禁状态

- 缺答编号：<无或编号列表>
- 冲突编号：<无或编号列表>
- 状态：READY / READY_WITH_RISKS / BLOCKED

## 正文成稿门禁十问

<按同样格式记录本门禁的 1–10 个问题与回答；不得用 Agent 自检结论代替用户回答。>

### 成稿门禁状态

- 缺答编号：<无或编号列表>
- 冲突编号：<无或编号列表>
- 状态：READY / READY_WITH_RISKS / BLOCKED

## 最终论文主线

- 核心贡献：...
- 各问题的方法、证据、结论和边界：...

## 证据缺口与降级处理

- 缺口：...
  处理：补实验 / 删除无证据论点 / 降低结论强度

## 后续动作

- 写作阶段：...
- 需要退回的建模、编码或文献任务：...
```

两个门禁中任一项缺答时，对应状态必须为 `BLOCKED`。报告只记录用户实际回答；用户回答“不确定”时应原样保留并记录保守处理，不得补写成确定决定。
